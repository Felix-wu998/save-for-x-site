隐私政策

Save for X 只做保存这一件事，没有开发者运营的服务器、分析跟踪、广告系统或用户账号。视频、GIF 与截图全部在你自己的设备上处理。

处理的数据存储与分享权限你的控制权

处理的数据

当你浏览 x.com 或 twitter.com 时，扩展会检查 X 当前展示的公开帖子结构，判断帖子里是否有可保存的公开视频或 GIF，并据此放置按钮。为此它会处理公开帖子的链接与帖子 ID。它不读取私信、你输入的内容或浏览历史。

为确认帖子里确实有可下载的媒体、并挑出最高码率的版本，扩展会把公开帖子 ID 发送到 X 的公开嵌入接口 cdn.syndication.twimg.com。视频文件直接从 video.twimg.com 下载到你的浏览器。

GIF 转换。 X 上的 GIF 实际是以 MP4 提供的。当你要 GIF 时，扩展会从 X 读取那个 MP4 源，并把它转换成真正的 .gif ，整个过程在你的浏览器内、通过一个不可见的本地扩展页面完成。转换不上传任何内容。

截图。 当你点击某条帖子的截图按钮时，扩展会调用 Chrome 的 tabs.captureVisibleTab，它返回当前标签页可见区域的图像。扩展随即在本地把图像裁剪为你点击的那条帖子，生成 PNG 并写入剪贴板。图像全程在你的设备上处理，不会发送给开发者或任何第三方，扩展也不保留它。

存储与分享

扩展开发者不收集、不存储、不出售、不分享你的个人数据、浏览历史、已下载的视频、X 账号凭据或公开帖子 ID。当前产品没有开发者运营的分析、广告、账号或视频处理后端。

公开帖子 ID 仅发送给 X，用于你请求的媒体查询。视频数据不会发送给扩展开发者。

各项权限的用途

  • x.com 与 twitter.com 站点访问： 识别符合条件的公开帖子，并放置下载与截图按钮。在其它任何网站上都不执行逻辑。
  • activeTab： 在你打开扩展弹窗时读取当前公开 X 帖子的网址。
  • downloads： 把选定的直连 MP4，或本地生成的 GIF，保存到 Chrome 的下载目录。
  • offscreen： 创建一个不可见的本地扩展页面，在你的设备上解码视频、编码 GIF。它不显示任何界面，也不上传任何内容。
  • clipboardWrite： 把你请求的截图写入剪贴板。扩展从不读取剪贴板内容。
  • cdn.syndication.twimg.com： 按公开帖子 ID 获取 X 的公开媒体版本清单。
  • video.twimg.com： 下载视频本身，或读取你请求转换的 GIF 所对应的 MP4 源。

可选权限：访问所有网站

截图依赖 Chrome 的 tabs.captureVisibleTab，该接口在技术上要求广泛的主机访问权限，或者 activeTab。而点击页面内的按钮不算「调用扩展」，因此 activeTab 永远不会通过这种方式被授予。

所以广泛主机访问被声明为 可选 权限。安装时不会申请，没有它下载功能也完全可用。第一次需要截图时，你自己在扩展弹窗里开启，Chrome 会弹出它自己的确认框。授予之后也只在你点击截图按钮时使用，扩展依然只在 x.com 与 twitter.com 上运行。

你的控制权

你可以随时通过 Chrome 停用或移除扩展。移除后扩展的一切处理都会停止。已经下载的文件仍在你自己的下载目录里，由你掌控。

本审核版网站不收集上线通知邮箱或支付信息。相关流程会在正式上线前提供更新后的隐私说明。
